ICONE ALLENATORI

Questa cartella è predisposta per contenere le icone/ritratti locali degli allenatori.
La V2 continua a usare il fallback con iniziali finché non viene definita una mappa nome -> file affidabile.

Formato consigliato: PNG/WebP quadrato, es.:
rosso-red.png
blu-blue.png
brock.png
max.png

In una versione successiva possiamo aggiungere trainer-icons.js per associare automaticamente i nomi.
